    9. Deriving the Inductance of a Coil (Solenoid).

    Faraday’s Law states that a primary coil would induce an opposing (negative) EMF in a nearby secondary coil:
    \begin{equation*} V_{induced} = - \frac{d \Phi_{B}}{dt} \end{equation*}
    Backing up a step, if the magnetic field hitting the secondary coil (B1) was constant and the total receiving area of the secondary coil (A2) was flat, we can break the \(\Phi_{B}\) back up into terms of the magnetic field and total receiving area:
    \begin{equation*} V_{induced} = - \frac{d\lbrack(\ \ \ \ \ \ )(\ \ \ \ \ \ )\rbrack}{dt} \end{equation*}
    Furthermore, if we let A­single represent the area of just one of the rings in the secondary coil, and if the secondary coil has N turns in it, we can rewrite the total receiving area of the secondary coil, A2, in terms of N and A­single:
    \begin{equation*} V_{induced} = - \frac{d\lbrack(\ \ \ \ \ \ )(\ \ \ \ \ \ )(\ \ \ \ \ )\rbrack}{dt} \end{equation*}
    Factor the two constants that can’t vary with time (because they are geometric properties of the equipment) out of the derivative:
    \begin{equation*} V_{induced} = - (\ \ \ \ \ )(\ \ \ \ \ )\frac{d(\ \ \ \ \ )}{dt} \end{equation*}
    Now substitute in the formula for B1. We know that B1 was the magnetic field generated by the primary coil, which is a solenoid. So, we’ll replace B1 with the library formula for the magnetic field of a solenoid:
    \begin{equation*} V_{induced} = - (\ \ \ \ \ )(\ \ \ \ \ )\frac{d\lbrack(\ \ \ \ \ \ )(\ \ \ \ \ )(\ \ \ \ \ )\rbrack}{dt} \end{equation*}
    Again factor out constants that can’t vary with time:
    \begin{equation*} V_{induced} = - (\ \ \ \ \ )(\ \ \ \ \ )(\ \ \ \ \ )(\ \ \ \ \ )\frac{d(\ \ \ \ \ )}{dt} \end{equation*}
    We group the bundle of constants in front of the derivative, which just depend on the geometric properties of the equipment, into a single constant. We call this constant the “coefficient of mutual inductance.” But we don’t actually need two coils to get an inductance, because the B field of the primary coil penetrates not just coil #2, but also coil #1. So if we realize that coil #1 receives magnetic field from itself, we can treat coil #1 as both the primary driver coil and secondary receiving coil, all in one. When writing the Vinduced for a coil upon itself, we group the bundle of constants in front of the derivative and call it a single constant L. L is called the coefficient of self-inductance but we usually just say L is the, “inductance,” for short, so the final equation is:
    \begin{equation*} V_{induced} = - (\ \ \ \ \ )\frac{dI}{dt} \end{equation*}
    This equation is the governing equation for the voltage in an inductor, analogous to how Q=CV is the governing equation for voltage in a capacitor, and V=IR is the governing equation for voltage in a resistor. So, we can use this with Kirchhoff’s Rules to solve circuits. Because of the minus sign, this says a coil carrying a current will generate a back-reaction upon itself. In other words, the current grows a magnetic field, and the magnetic field growth creates a negative EMF that tries to slow the current down. Thus, putting a coil of wire in a circuit will buffer the circuit against sudden changes in current and allow smoother ramp-ups and ramp-downs of current. The SI unit for the inductance L is the Henry (H). Simply by rearranging the units in the Vinduced equation, we see that the Henry is made up of the following units:
    \begin{equation*} Henry = Volt\left( \frac{\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ }{\ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ \ } \right) \end{equation*}
